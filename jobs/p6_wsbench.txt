# P6: WorkspaceBench's own multi-token items (six families, vendored at data/wsbench/ from camilablank/workspace-bench commit 92d763e,
# 2026-09-23) on OUR models, the bench's read site (final prompt token, plain render), its regex scorer (raw; token bags without the
# LLM summarizer - see docs/P6_BACKEND_NOTE.md), gated on our model (greedy plain continuation + every bridge question; documented
# tolerance vs the bench's 8/10 sampled gate; agent H's gate, --gate-tokens 48, greedy only). Format: name<TAB>python-args<TAB># ~A100-h;
# Each line: <run name> TAB <arguments to python, relative to the repository root>; one GPU per line.
#
#   * the X3 arm is the project's BEST reader: h read at every read layer of the grid is patched into the carrier AFTER block t for
#     t in {same, 4, 8} (--x3-target-layer same,4,8; arms x3_identity3 / x3_identity3_t4 / x3_identity3_t8), 8 identity3 carriers
#     (A12: exemplars checked against every item string and every bench alias; identity2 is NOT used), 8 greedy tokens, one prose
#     sample per carrier cut at the carrier stops -> the bench's any-sample rule = X3's "any of 8"; every generation is written to
#     runs/<tag>/readouts/<arm>[__shuffled]/<family>.jsonl in the bench contract and scored with the vendored bench regex.
#   * read layers = the whole grid (14B 16,24,32,36,38; 1.7B 10,14,18,22,25,27): the bench's any-layer rule over OUR layers; the
#     J-lens (bench cosine readout, top-10), the logit lens and the plain chains are read on the SAME cells (each token / bag arm
#     also reports `on_read_layers`).
#   * no P3 (optional via --readers p3; expensive and not the best reader, FULL_REPORT 4.15); no --tau-from (tau is optional, the
#     P3 ranking defaults to the last-step rule A11c; prefixes are stored so p3 can be re-ranked offline with --rescore).
#   * the 1.7B lens file stops at block 26: the jlens arms skip L27 automatically (logged); everything else runs at all six layers.
# Cost model (LOG): 14B ~0.75-1.5 s per 8-token generation (bf16-mixed), 1.7B ~0.25 s; per gated item 8 carriers x 3 targets x
# n_read_layers x 2 conditions = 240 (14B) / 288 (1.7B) generations -> ~4 min (14B) / ~1.2 min (1.7B); gate ~1-3 s per item
# (16-token greedy + bridge questions). Gated fractions are unknown (the banks were gated on a 27B): ~40 % assumed on 14B (the
# smoke gated 3 / 3 basic_readout, 0 / 3 multihop), ~15 % on 1.7B. With a bench checkout on the HPC add
# --wsbench-root workspace-bench to every line (bench JLens / LogitLens classes + scorer; same numbers).
# Decision rule (N1, report-only pilot): X3 any-layer raw-regex pass on basic_readout_mt (14B) >= 0.10 with the shuffled control
# <= 0.02 -> proceed to the 27B and write the bench table; <= 0.02 on every family -> the reader does not transfer.
